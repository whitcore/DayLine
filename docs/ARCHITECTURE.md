# Устройство Dayline

## Учёт времени

`native/ForegroundProbe.cs` опрашивает активное окно Windows и время последнего ввода.
`native/BrowserProbe.cs` через доступность Firefox распознаёт домен активной вкладки.
Оба помощника компилирует `scripts/build-native.ps1`; Electron запускает их как дочерние процессы.

`desktop/tracker.cjs` создаёт интервалы только для окна на переднем плане.
Пауза, бездействие, блокировка, сон и пропуски замеров исключаются из учёта.
`desktop/model.cjs` делит интервалы на локальные дни и рассчитывает сводки.
`desktop/summary-cache.cjs` индексирует историю и кеширует сводки по датам.

## Категории и рейтинг

Программа может иметь одну категорию или распределение по долям с суммой 100%.
Свои виды привязаны к работе, нейтральному времени или отдыху.
Категория домена заменяет распределение браузера только для интервалов этого домена.
Без отдельной категории сайт наследует доли браузера. Сырые интервалы остаются прежними.

`desktop/focus-settings.cjs` задаёт расчёт рейтинга: доля полезного времени или дневная цель.
`desktop/focus.cjs` ведёт отдельный таймер работы/перерыва по срокам завершения.
Таймер не добавляет выдуманные рабочие минуты в учёт активных окон.

## Данные

Профиль находится в `%APPDATA%\Dayline\dayline.json`, иконки — в соседней папке `icons`.
`desktop/storage.cjs` проверяет схему и сохраняет JSON атомарно с предыдущей копией.
Дополнительные поля профиля версии 1 имеют значения по умолчанию для старых резервных копий.
Экспорт включает пользовательские иконки. Импорт проверяется и требует подтверждения в приложении.

Личные профили, резервные копии, тестовые результаты, журналы и установщики исключены из Git.
Тесты используют искусственные данные в отдельных папках `test-results`.

## Интерфейс и изоляция

React работает в изолированном renderer без Node integration.
`desktop/preload.cjs` предоставляет ограниченный набор IPC-методов.
Основной процесс проверяет источник IPC и входные значения.
Для повседневной работы соединение с сервером не требуется.

`src/themes.css` определяет палитры, `src/motion.jsx` — политику движения и общие компоненты.
Анимации преимущественно используют transform/opacity; уменьшение движения и клавиатура учитываются отдельно.
График загружается при открытии статистики. Шрифт и ресурсы поставляются локально.
