# Обновление Dayline с 1.4.0 до 1.5.0

Установщик `Dayline-Setup-1.5.0.exe` предназначен для Windows x64 и устанавливает приложение для текущего пользователя.

1. В Dayline 1.4.0 открой «Настройки» и нажми «Сохранить копию». Сохрани файл в удобную папку.
2. Щёлкни правой кнопкой мыши по значку Dayline в области уведомлений Windows и выбери «Выход из Dayline».
3. Запусти `Dayline-Setup-1.5.0.exe`. Оставь путь действующей установки и заверши обновление.
4. Открой Dayline и проверь историю, дневник и категории. Приложение использует прежний профиль `%APPDATA%\Dayline`. Если понадобится загрузить сохранённую копию, в настройках выбери «Восстановить».
